  • ✅ Validação automática

📁 Gerenciando Projetos

ℹ️

Projetos são a base do Hub Jurídico. Cada projeto contém arquivos, configurações e dados.

Como Criar um Novo Projeto?

1

Clique em "📁 Projetos"

Na barra lateral esquerda, selecione a opção Projetos

2

Clique em "+ Novo Projeto"

Você verá um botão para criar um novo projeto

3

Preencha os Dados

Digite o nome, descrição e configurações do seu projeto

4

Clique em "Criar"

Seu projeto será criado e você poderá começar a trabalhar

Campos do Projeto

Campo Descrição Exemplo
Nome Nome do seu projeto Meu Projeto Jurídico
Descrição O que o projeto faz Gerenciador de contratos
ID (Package) Identificador único com.app.meu_projeto
API Min Versão Android mínima 21
API Max Versão Android máxima 33
Orientação Retrato ou Paisagem portrait
⚠️

Dica: O ID do projeto deve ser único e seguir o padrão com.app.nome_projeto

✏️ Editando Arquivos

ℹ️

O Editor permite editar todos os arquivos do seu projeto com destaque de sintaxe.

Como Editar um Arquivo?

1

Selecione um Projeto

Clique em um projeto na lista de projetos

2

Clique em "✏️ Editor"

Na barra lateral, selecione a opção Editor

3

Escolha um Arquivo

Clique em um arquivo na lista para abrir no editor

4

Edite e Salve

Faça suas alterações e clique em "💾 Salvar"

Tipos de Arquivo Suportados

  • 📄 HTML - Estrutura da página
  • 🎨 CSS - Estilos
  • ⚙️ JavaScript - Lógica
  • 📦 JSON - Configurações
  • 📝 Markdown - Documentação
  • ⚖️ Jurídico - Documentos legais
✅

Dica: Use Ctrl+S para salvar rapidamente!

🤖 Usando a IA

ℹ️

A IA ajuda a analisar, validar e melhorar seu código jurídico.

Funcionalidades da IA

📖

Analisar Código

Receba análise detalhada do seu código

✅

Validar Conformidade

Verifique se o código segue as normas jurídicas

💡

Sugerir Melhorias

Obtenha recomendações de otimização

🔍

Revisar Documentação

Valide documentação e comentários

Como Usar a IA?

  1. Clique em "🤖 IA" na barra lateral
  2. Escolha uma função (Analisar, Validar, etc)
  3. Cole seu código ou selecione um arquivo
  4. Clique em "Analisar"
  5. Aguarde o resultado da IA
  6. Implemente as sugestões
⚠️

Nota: A IA funciona melhor com código bem estruturado e comentado.

🔧 Gerando Aplicativos

ℹ️

O Gerador cria APK, PWA e versões desktop do seu projeto.

Tipos de Geração

📱 Capacitor

Gera APK para Android e iOS

🍎 EAS

Expo Application Services

🖥️ Electron

Aplicativo Desktop (Windows, Mac, Linux)

🌐 PWA

Progressive Web App

Como Gerar um APK?

1

Clique em "🔧 Gerador"

Na barra lateral, selecione Gerador

2

Escolha "📱 Capacitor"

Selecione a opção de geração APK

3

Configure as Opções

Defina versão, permissões, ícones, etc

4

Clique em "Gerar"

Aguarde a geração e baixe o arquivo

✅

Dica: Valide seu projeto antes de gerar para evitar erros!

🌐 Sincronizando com GitHub

ℹ️

GitHub permite fazer backup e compartilhar seu projeto.

Como Sincronizar com GitHub?

1

Crie um Repositório

Acesse github.com e crie um novo repositório

2

Clique em "🌐 Repositório"

Na barra lateral, selecione Repositório

3

Conecte sua Conta

Faça login com sua conta GitHub

4

Sincronize

Clique em "Sincronizar" para enviar seu projeto

Benefícios do GitHub

  • 💾 Backup automático do seu projeto
  • 🔄 Sincronização entre dispositivos
  • 👥 Compartilhe com outros desenvolvedores
  • 📊 Histórico de alterações
  • 🔐 Segurança dos dados
⚠️

Importante: Nunca compartilhe dados sensíveis no GitHub público!

❓ Perguntas Frequentes

Como faço backup do meu projeto?

Você pode fazer backup de duas formas:

  1. Sincronizando com GitHub (automático)
  2. Exportando o projeto como ZIP

Posso editar múltiplos arquivos ao mesmo tempo?

Sim! O editor permite abrir múltiplas abas. Clique no arquivo para alternar entre eles.

Como faço para gerar um APK assinado?

No Gerador, selecione "Capacitor" e marque a opção "Gerar APK Assinado". Você precisará fornecer sua chave de assinatura.

A IA pode revisar meu código jurídico?

Sim! A IA pode analisar, validar e sugerir melhorias no seu código jurídico. Use a função "Analisar Código" no módulo IA.

Como importo um projeto existente?

Clique em "📁 Projetos" e depois em "Importar Projeto". Selecione um arquivo ZIP ou conecte um repositório GitHub.

Meu projeto não está salvando. O que faço?

Tente:

  1. Recarregar a página (F5)
  2. Verificar sua conexão com a internet
  3. Limpar cache do navegador
  4. Contatar suporte se o problema persistir

Posso usar o Hub Jurídico offline?

Sim! O Hub Jurídico é um PWA e funciona offline. Seus dados serão sincronizados quando você voltar online.

Como obtenho suporte?

Você pode:

  • 📧 Enviar email para suporte@hubjuridico.com
  • 💬 Abrir uma issue no GitHub
  • 📞 Ligar para nosso suporte técnico
